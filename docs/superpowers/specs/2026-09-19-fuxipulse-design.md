# FuxiPulse Design Spec

AI decision-support dashboard for homestay weak-season operations.

## Stack
Vite + React + TypeScript + Tailwind CSS + React Router + Recharts

## Visual
- Navy `#0B1F3A`, teal `#0D9488`, white/slate surfaces
- Font: Plus Jakarta Sans
- Sidebar shell, calm SaaS hospitality aesthetic

## Routes
- `/` Dashboard
- `/weak-season` Predict & Diagnose
- `/research` Research Agent
- `/strategy` Strategy Center + Human Approval
- `/ota` OTA Operations
- `/knowledge` Knowledge Base
- `/feedback` Performance Feedback

## Data
Mock Tengchong property data; local UI state for approve/reject.
